# StraforAI Observability Runbooks

This directory contains operational runbooks for alerts generated by the
StraforAI observability stack (Prometheus + Alertmanager + Grafana).

## How to use these runbooks

1. When an alert fires, Alertmanager sends:
    - An email to `ALERT_EMAIL_TO`.
    - A webhook to `POST /api/admin/alerts/webhook` which stores the alert in
      the `alerts` table and shows it in the admin Notifications Viewer.
2. Each alert includes a `runbook_url` annotation pointing to the relevant
   file in this directory.
3. Open the runbook for diagnosis steps, mitigation actions, and escalation
   procedures.

## Alert severity levels

| Severity | Response time     | Escalation           |
| -------- | ----------------- | -------------------- |
| Critical | Immediate (24/7)  | Page on-call + email |
| Warning  | Within 4 hours    | Email only           |
| Info     | Next business day | Webhook only         |

## Quick reference

### Start the observability stack (Docker Compose)

```bash
docker compose up -d
```

### Start with dev ports published

```bash
docker compose -f docker-compose.yml -f infra/compose/docker-compose.observability-dev.yml up -d
```

### Check Prometheus targets

```bash
curl http://localhost:9090/api/v1/targets | jq '.data.activeTargets[] | {job: .labels.job, health: .health}'
```

### Check Alertmanager alerts

```bash
curl http://localhost:9093/api/v2/alerts | jq '.[] | {alertname: .labels.alertname, state: .status.state}'
```

### View Grafana dashboards

Open `http://localhost:3010/admin/monitoring` in the browser (requires admin login).

### Acknowledge an alert

```bash
curl -X POST http://localhost:3010/api/proxy/admin/alerts/1/ack \
  -H "Authorization: Bearer <token>"
```

### Create a silence

```bash
curl -X POST http://localhost:9093/api/v2/silences \
  -H "Content-Type: application/json" \
  -d '{"matchers":[{"name":"alertname","value":"ContainerDown","isRegex":false}],"startsAt":"2025-01-15T00:00:00Z","endsAt":"2025-01-15T01:00:00Z","createdBy":"admin","comment":"Maintenance"}'
```
